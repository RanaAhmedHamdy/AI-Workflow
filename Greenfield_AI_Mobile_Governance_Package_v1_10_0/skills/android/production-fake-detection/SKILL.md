# Production Fake Detection

Scan production source sets and release composition for manufactured provider results, fixed success IDs, accept-all validators, placeholder authorization, no-op workers/schedulers/repositories, sentinel queries, in-memory substitutes for required durable state, inline fake flags, direct fake fallbacks, and debug/preview bindings.

Classify every finding as removed, isolated to approved non-production source sets, or blocker. Return `PASS` or `FAIL`.
