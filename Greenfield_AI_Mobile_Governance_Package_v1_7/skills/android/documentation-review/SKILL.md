# Documentation Review

Verify provenance/revision/scope/exclusions; facts versus decisions/recommendations; source/test/runtime/release evidence limits; `Needs verification`; current versus historical status; links and routing; duplicate/conflicting claims; architecture-coverage completeness; and whether the document is useful without authorizing changes.

Return: document, quality, unsupported claims, missing material information, stale/conflicting claims, overconfidence, routing/provenance issues, smallest edits, and decision (`Approved`, `Approved after edits`, `Not approved`).
