# iOS Adaptive and Accessibility Readiness

Establish applicable support:

- iPhone device classes and orientation;
- iPad compact/regular widths, Split View, Slide Over, Stage Manager;
- multiple scenes/windows and external display;
- keyboard, pointer, trackpad, Full Keyboard Access, Switch Control, Voice Control;
- Catalyst or Designed for iPad;
- Dynamic Type including accessibility sizes;
- VoiceOver labels, values, traits, actions, headings, rotor/focus order;
- Increased Contrast, Reduce Motion, Reduce Transparency;
- safe areas, keyboard, sheets, popovers, toolbars, menus.

Flag fixed sizes, compact-only assumptions, hidden actions at large text, meaning by color alone, focus loss, inaccessible custom controls, and claims based only on previews/snapshots.

Require named simulator/device scenarios and results.
