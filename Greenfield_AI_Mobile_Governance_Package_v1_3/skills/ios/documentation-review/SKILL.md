# Documentation Review

Verify:

- authority and scope;
- current versus historical status;
- facts versus decisions versus proposals;
- review provenance;
- evidence limits;
- unresolved `Needs verification`;
- duplicate or conflicting claims;
- routing and links;
- architecture coverage;
- whether the document accidentally authorizes work.

Return:

- document;
- quality;
- unsupported claims;
- stale/conflicting claims;
- missing material information;
- smallest required edits;
- decision: `Approved`, `Approved after edits`, or `Not approved`.
