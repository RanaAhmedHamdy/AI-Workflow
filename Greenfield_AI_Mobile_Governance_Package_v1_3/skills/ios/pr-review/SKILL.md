# PR Review

Read policy, routed context, PR/task description, complete target-branch diff, and nearby tests.

Review:

- behavior and acceptance criteria;
- architecture and dependency direction;
- target/package membership;
- state and lifecycle;
- concurrency and cancellation;
- persistence and migrations;
- localization, adaptation, accessibility;
- privacy/capability changes;
- production fakes;
- documentation impact;
- exact evidence and unverified layers.

Report blockers, non-blockers, questions, test gaps, commands run, and runtime layers not proven. Do not merge or authorize publication.
