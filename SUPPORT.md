# Support

AI-Workflow is maintained as an open technical project. For usage questions, workflow discussion, or improvement ideas, open a GitHub Discussion when available or use the feature-request issue template. Please include the profile, workflow, platform, command, and non-sensitive observed result.

For reproducible defects, use the bug-report template. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not disclose details in a public issue.

Support is best-effort; this project does not provide production incident response, SLA-backed support, or a guarantee that every coding agent or native toolchain is compatible.
